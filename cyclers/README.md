# Cyclers
This repository contains hardware documentation, control code, LabVIEW programs, configuration files, and other resources for the battery cyclers used in the lab.

## nhr-9200-three-cell-chamber
* Cabinet-based NHR 9200 system with three independent 4960 power modules.
* Supports simultaneous testing of up to three cells.
* Cells are housed in an InQ temperature-controlled chamber to maintain a consistent test temperature.
* Each channel is rated for up to 600 V DC, 40 A, and 12 kW.

## nhr-9200-liquid-cooled-single-cell
* Cabinet-based NHR 9200 system with three independent 4960 power modules.
* Configured for individual cell testing, with one cell connected to each channel.
* Cells are placed in insulated test enclosures and maintained at the target temperature using forced-water cooling.
* Each channel is rated for up to 600 V DC, 40 A, and 12 kW.

## nhr-9200-high-current-single-cell
* Cabinet-based NHR 9200 system with three independent 4912 high-current power modules.
* Currently configured primarily for single-cell testing.
* Uses large, high-current cables that are heavier and less flexible than the cables used with the other cyclers.
* Each channel is rated for up to 120 V DC, 200 A, and 12 kW.

## itech-three-cell-chamber
* Custom three-cell cycler built using three ITECH IT-M3412 bidirectional DC power supplies.
* Supports simultaneous testing of up to three cells.
* Cells are housed in an InQ temperature-controlled chamber to maintain a consistent test temperature.
* Each channel is rated for up to 60 V DC, 30 A, and 200 W.
