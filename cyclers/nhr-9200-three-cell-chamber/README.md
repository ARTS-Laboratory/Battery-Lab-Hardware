# nhr-9200-three-cell-chamber
* Cabinet-based NHR 9200 system with three independent 4960 power modules.
* Supports simultaneous testing of up to three cells.
* Cells are housed in an InQ temperature-controlled chamber to maintain a consistent test temperature.
* Each channel is rated for up to 600 V DC, 40 A, and 12 kW.
